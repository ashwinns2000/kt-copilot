# KT Copilot — AI-Powered Knowledge Transfer Platform

## Overview

KT Copilot is a full-stack AI-powered application designed to simplify knowledge transfer in software development teams. It helps developers understand project documentation, troubleshoot issues, and onboard new team members using Generative AI.

## Problem Statement

Software project knowledge is often scattered across technical documents, API specifications, setup guides, and troubleshooting notes. This makes knowledge transfer time-consuming and can lead to information gaps when team members join or leave a project.

KT Copilot aims to centralize this knowledge and make it accessible through an intelligent assistant.

## Planned Features

- **Document Management:** Upload and organize project documentation.
- **AI Knowledge Assistant:** Ask questions about uploaded documents.
- **Source Citations:** Trace AI answers back to relevant document passages.
- **Onboarding Assistant:** Generate learning paths and onboarding checklists.
- **KT Document Generator:** Create structured knowledge-transfer documentation.
- **Troubleshooting Assistant:** Find relevant troubleshooting steps from project knowledge.
- **Project-Based Access:** Keep project information accessible only to authorized users.

## Technology Stack

- **Frontend:** Angular
- **Backend:** Java, Spring Boot
- **Generative AI:** Gemini API, Spring AI
- **Database:** PostgreSQL
- **Vector Search:** pgvector
- **Testing:** JUnit, Mockito, Angular testing tools
- **Deployment:** Docker

## Architecture

Angular Frontend → Spring Boot REST APIs → AI/RAG Pipeline → PostgreSQL and Vector Search
